First release of LogLens: a self-hosted log viewer that ranks every event by severity and explains logs with AI.

## What's included

- **Severity first**: every log is labelled critical, important, warning or normal. Rules decide first; the AI classifies whatever no rule matches and never hides logs.
- **AI assistant**: explain any log line in plain language, ask questions such as "were there SSH brute force attempts today?" and get answers that cite real timestamps. Works with Ollama (local) or any OpenAI-compatible API, including Gemini. IPs and usernames are masked before they leave your server.
- **Live view, overview and alerts**: live tail, 24 h overview, and critical alerts pushed to your phone through ntfy.
- **Web app (PWA) and Android app**, dark and light themes.
- **Agent**: Vector pipeline for journald, Docker and nginx/apache/auth.log, installed with one script on Debian/Ubuntu and Fedora.

## Install

1. On the LogLens server (Docker with the Compose plugin):
   ```sh
   tar xzf loglens-deploy-0.1.0.tar.gz && cd loglens-deploy-0.1.0
   bash init-env.sh          # generates the admin password, secrets and push token
   docker compose pull && docker compose up -d
   ```
   Open `http://<server>:8080` and sign in with the admin password printed by `init-env.sh`.
2. On every server you want to monitor:
   ```sh
   tar xzf loglens-agent-0.1.0.tar.gz && cd loglens-agent-0.1.0
   sudo bash install-agent.sh http://<loglens-server>:8080 <LOGLENS_PUSH_TOKEN>
   ```
3. Android: install `LogLens-0.1.0-arm64.apk` and enter your server URL on the login screen.

Verify downloads with `sha256sum -c SHA256SUMS`.
